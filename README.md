# graphiques-bourse

Page de graphique de cours (widget gratuit TradingView) à intégrer dans Notion avec un bloc « Embed ».

Lien : `https://othmanhassani.github.io/graphiques-bourse/graph.html?symbol=BOURSE:TICKER`

Exemples : `NASDAQ:SYM`, `NASDAQ:ISRG`, `TSE:6954`.
Options : `&range=1M` (par défaut ; 3M, 12M, 60M, ALL), `&interval=D` (D, W, M), `&theme=light|dark`.
